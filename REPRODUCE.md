## Dates

Each commit is dated at noon (Pacific/Guadalcanal) on the day the change took effect. The other dates, enacted and published, are trailers.

When a law gives no date of its own, the default rule applies: Solomon Islands Independence Order 1978 s. 1(2) and s. 2(1): the Constitution came into operation on the appointed day, 7 July 1978 http://www.paclii.org/sb/legis/consol_act/c1978167/

## Commands, in order

```sh
# fill the cache from the sources listed above (network; Lexifina's fetch scripts are kept privately)
python -X utf8 tools/parse.py                  # cache -> corpus.json (no network)
python -X utf8 tools/build.py <folder> --repo <empty folder> --docs-date 2026-10-28
python -X utf8 tools/check_repo.py <repo> --corpus <folder>/corpus.json --write
python -X utf8 tools/build.py <folder> --repo <another empty folder> --docs-date 2026-10-28 --compare <repo>
```
