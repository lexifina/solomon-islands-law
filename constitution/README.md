# The Constitution of Solomon Islands

The Schedule to the Solomon Islands Independence Order 1978 (S.I. 1978/783), in force from 7 July 1978, and every later version recorded here. The current text is the reprint the Attorney-General publishes under the Legislation Act 2023 (<https://attorneygenerals.gov.sb/legislation/legislation-portal/>); see `git log -- constitution/` for the versions and the Acts that made each change.
